# Shimmer v1 report

**In one sentence.** On the four public benchmarks measured, Shimmer's full pipeline found none of the gold flags on ContractNLI (where it ties the bare model on precision, recall, F1 and accuracy, and the bare model leads on correct refusals), scores below the bare model on ContraDoc and CUAD, and is about even on SciTab; it leads on the synthetic development suite, whose rules are the kind its own computations were built for. The measured reason for the gap: on the public benchmarks the local judging model's answers mostly copy its contract's own filled example, which the quote rule refuses, so nothing is kept, and Shimmer's correct labels there come from saying nothing, not from detection (D-178). Every figure is a development figure on exposed material (`docs/RESULTS.md`); no held-out or sealed result exists yet.
