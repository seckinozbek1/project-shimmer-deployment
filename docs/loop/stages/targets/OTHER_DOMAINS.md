# D-S77: light benchmarks from other domains

Written 2026-11-08 (about 18:30 UTC) by the target-table research lane. I read only papers,
repository READMEs and LICENSE files, and dataset cards; I opened no data file or viewer. "Verified"
means read at the source named. Costs are not measured: "few dollars" assumes a development sample
of a few hundred items on the loop's A10.

Training-mix families checked against: C4, MultiNLI, WANLI, TabFact, TAT-QA, FinQA, GovReport,
BillSum, QASPER, PubMedQA, VitaminC, PAWS, WikiAtomicEdits. I treat Wikipedia as a shared family:
VitaminC and WikiAtomicEdits are both built from Wikipedia, and TabFact's tables are Wikipedia
tables. C4 is a 2019 Common Crawl web snapshot, so any set built from public web pages published
before 2019 may share pages with it. The papers cannot settle that question; only a URL check
against C4 can.

Recommendation: take PUBHEALTH, after role B's C4 URL check, as the one other-domain set. If a second
set is wanted, take PubHealthTab once its data licence is confirmed (it is SciTab's task in health),
or SummEdits' News (2023) and ECTSum domains once their source licences are verified. Two of
Seckin's three choices in D-S77 item 4 fail item 1's overlap rule as I read it: TabFact (in a
training mix) and WikiContradict (Wikipedia family). That should go to FOR_SECKIN per item 4.
