## Initial candidate decisions

Do not gate production or verification solely on convention subjects. Production
has responsibilities outside that assignment and feeds later review. Retain
corpus indexing, institutions, citation chains and speech-act work conservatively:
this run declares no authoritative exclusion of their expertise, and bus/report
consumers exist. Empty recovered baseline output is not advance proof that an
agent has no useful work on a new run.

Do not suppress legal deepening from the apparent domain or unsupported-looking
prose. That would require substantive relevance judgment, not structural routing.
No new keyword gate, token cut, model change or retry is justified here.

Preserve existing exact assignment, per-plan arithmetic/refusal, optional polish,
privacy and editorial conditions. Dense reference means those existing conditions
within valid task/governance state, not forcing every agent. Sparse must remain
conservative when no additional justified exclusion exists. No additional call
reduction has yet been demonstrated or accepted.

## Implemented architecture and profiles

`--activation-profile dense` remains the default reference. `sparse` exposes the
same current conservative policy and records retained activation explicitly.
Neither profile adds an expertise exclusion. Existing conditional routes remain
in their owning phases; their decisions use the common record shape rather than
being moved into a semantic super-router. This is an auditability improvement,
not a claim of newly reduced conditional compute or an optimized sparse build.

The lifecycle is eligibility, activation, argument/context preparation, actual
dispatch attempt, contract/backend outcome, and possible bounded later work.
`scripts/agent_activation.py` writes `audit/agent_activation.json` atomically under
the existing run context. It contains the registry's 18 identities, individual
decisions and per-agent latest states plus accumulated dispatch counts. Read the
individual phase/document decisions when an agent was active earlier and inactive
later; a final inactive decision does not erase an earlier call.

Each decision carries agent, eligible, activated, mode, reason, evidence, trigger
source, structural/governed-semantic/escalation kind, phase, document, repeat
count/limit, downstream purpose, state and call ID. An activated request can fail
before dispatch. A dispatch attempt can fail at the backend or contract boundary.
`actual_call` means dispatch was attempted, not that generation succeeded. Actual
generation, tokens and resource use remain independently measured. The call ID
joins the existing call-evidence and cost records. No audit text enters prompts
or the model bus.

The states distinguish `eligible_inactive`, `ineligible`, `no_execution_path`,
`activated_not_dispatched`, `dispatch_started`, `completed`,
`pre_dispatch_failure` and `execution_failure`. Before a phase is reached its
eligibility is unknown (`null`), not a fabricated refusal or a successful skip.
The common record observes the existing eligibility gates; it does not confer
new constitutional permission. If its persistence fails before dispatch, no
unrecorded call is deliberately allowed through. An interrupted process can leave
an unfinished state, which must be read with run-completion evidence.

Legal follow-ups retain the existing first-six, serial policy and record the
original finding item ID and ordinal. Findings beyond the cap keep their initial
form. An initial failure is not retried. Editorial ranks retain the operator's
confidence/out-of-mandate triggers, accumulated prior observations and configured
climb cap. A higher rank is a newly activated agent, not a retry of the lower
rank. Privacy continues to refuse the board on sensitive runs and to gate the
local redactor on layer/rules/deliverable state. Optional polish still requires
typed irregular findings, and the template remains the amendment author.

Repeat counters describe follow-up analysis of an initial legal result. Distinct
document tasks, finite convention plans and per-finding wording tasks are counted
as separate scheduled work, not contract retries. Their document/unit/rule/plan
evidence links to the owning finite input collection. Editorial records identify
the prior rank and climb ordinal; the existing board summary and inactive-rank
records retain the configured climb cap. None of these paths retries a failed
contract or recursively schedules another copy of itself.

No agent responsibility, model, output cap, generation configuration, five-voter
mechanism, source/grounding role, convention semantics, constitution or scorer
has been changed. No new semantic gate or contract-failure retry is introduced.
The generated harness was rebuilt through its builder. Its amendment description
now names the actual per-finding polish path and separate direct Draft memo call.
Further source tracing corrected the initial inventory draft's mistaken attribution
of that memo call to PROCESSOR: the real caller uses AMENDMENT_DRAFTER.
