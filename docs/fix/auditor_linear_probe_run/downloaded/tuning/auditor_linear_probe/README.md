# Authorized Auditor classification-first linear probe

Design commit: `25f7dc0cb1bd11d652debbec52940f84e9d64193`.
Operator authorization: attachment `9f0ba690-8742-4328-9662-7a330e3321db`.

One frozen Phi-3.5-named/LlamaForCausalLM base plus the exact frozen Auditor step120 LoRA; one new 15,365-parameter linear head. Only the head trains, for 200 full-batch updates. Data/split are exact byte copies of the Auditor-only canonical export, not new examples. Classifier prompts alias citation numbers; original prompts remain for refusal and reason generation. See experiment.json for source identities, exact controls, head parameters and all historical gates.

The native last decoder hidden state is obtained directly from the underlying LlamaModel with all LoRA projections active, no gradients, no cache, no intermediate layer retention. It includes final normalization. The last non-padding position is -1 because each feature call is unpadded batch1. Population standard deviation (ddof=0), computed in FP32 from TRAIN only, is the prospectively fixed interpretation of the design's standardization.

Refusal recognition follows saved original greedy branch semantics, requiring the configured native EOS after the refusal object. Reason decoding starts after the forced opening string and stops at the first valid unescaped closing quote. The last subword token can contain punctuation following that quote: preserve it as same-token spill, count the entire generated token, and serialize only the exact decoded reason string. No reason is repaired. The generated allowance is 192 minus the tokenizer count of an empty assembled answer including termination, plus two boundary-merge tokens. Actual full assembled tokenization is authoritative; overflow fails, never truncates. The native termination of the assembled contract is explicitly tagged as deterministic, not model-generated throughput.

Controls regenerate frozen features and require exact vector, logit, prefix token, reason token, routing, assembled JSON, scorer and stop identity. Timings/memory are excluded from identity comparisons. Every raw intermediate row is flushed and fsynced before scoring. Only complete fresh 60-row evidence permits PASS/FAIL. Runtime interruption means INDETERMINATE.

Local tests use cached tokenization, saved output replay and synthetic stand-ins. They do not execute a backbone, generate text or train an experimental candidate. The local Anaconda Torch import collides with an existing OpenMP runtime; no unsafe duplicate-runtime override was used. Feature indexing/autograd/cache behavior and 200-update orchestration are tested with stand-ins; real pinned Torch/CUDA/PEFT integration is checked on the single authorized instance, without a rescue run.

One A10 at observed $1.29/hour. Conservative prospective bound: 600s setup + 300s feature extraction + 70*(155 reason + 16 prefix tokens)/6 tok/s + 60s head/checks + 300s cleanup = 3255s, $1.166375. This upper planning envelope fits 55 minutes; typical output lengths imply the earlier 30–50-minute estimate. Runtime projects remaining work from measured rates and fails closed if it cannot finish by minute50. No new work starts after minute50; remote SIGTERM watchdog also enforces that boundary. Independent local provider watchdog starts termination at minute53, reserving two minutes for provider confirmation by minute55. Collection subprocess timeouts are bounded by minute53. Provider delays cannot be guaranteed away; record actual confirmation time and any breach, and continue cleanup until absent.

No Producer payload, protected data, additional head, fallback, folds1–4, causal-LM training, LoRA updates, full pipeline, governance run, multi-round or push. Historical results remain immutable. Runtime bundle includes only reviewed code, 300 Auditor rows, prompt bindings, and the single authorized frozen Auditor adapter. Credentials never enter the bundle or evidence archive.
