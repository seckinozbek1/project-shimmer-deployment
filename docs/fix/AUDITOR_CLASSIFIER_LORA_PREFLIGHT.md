# Auditor classifier-specific LoRA preflight

This is one new classification-only experiment after `8a11669`. All historical verdicts, evidence and adapters remain immutable. V2 remains `AUDITOR_EXTERNAL_RELATION_DATA_V2_NOT_READY`; this is a one-off diagnostic data exception.

Architecture is explicit: pinned base → **fresh rank-8 classifier LoRA** → final normalized hidden state at the last non-padding prompt token → four-way FP32 linear head. The historical step120 adapter is neither loaded, stacked, initialized from, nor included in the cloud payload. No previous feature cache is used. There is **no population feature standardization**. The new head is zero-initialized with seed 7; there is no scheduler. The earlier generative experiment's schedule does not govern this new classification-only objective.

The pinned base is `unsloth/Phi-3.5-mini-instruct-bnb-4bit`, revision `5c20803aa197416f43fb455e55c85178775320cb`, expected `LlamaForCausalLM`, hidden size 3072. Base/config/tokenizer hashes are inherited exactly from the completed diagnostic. `prepare_model_for_kbit_training` freezes the base, casts nonquantized tensors to FP32, and enables gradient checkpointing. The immutable runtime base-state comparison begins after this deterministic preparation, before training.

LoRA: rank 8, alpha 16, dropout .05, bias none, CAUSAL_LM-compatible wrapper, q/k/v/o/gate/up/down projections. Fresh default PEFT initialization, seed 7, B matrices initially zero. Expected LoRA parameters **14,942,208**, head **12,292**, total **14,954,500**; no base or LM-head parameter is trainable. The remote runtime must verify the actual inventory before constructing the optimizer.

Exact inherited records: TRAIN **1,792** (192 historical + 1,600 external, 448/class); external DEV **200**, historical substantive DEV **48**. SHORTER and LONGER each use the existing 75 IDs. `records.json` and `challenges.json` are byte-identical to the prior preflight. Only `input_ids` enter the model; ID, split, label and provenance never enter the prompt. The mixed external corpus is not reopened, and HOLDOUT is not deserialized, included or evaluated. The receipt remains unconsumed.

Two deterministic seed-7 shuffled complete passes preserve exact membership and class counts. Microbatch 1, accumulation 4, effective batch 4: **448 updates/pass, 896 total**. The complete schedule is bound before launch. Checkpoints **448 and 896** are both mandatory; no update follows 896. Four-way CE plus `.001 * mean(W**2)` is accumulated equally over four rows. AdamW groups: LoRA LR `1e-4`, head LR `.01`, betas `.9/.999`, epsilon `1e-8`, weight decay 0; combined gradient clipping norm 1. No scheduler, weighting, calibration, generation, refusal or explanation loss.

Evaluation is in eval/inference mode, and optimizer/trainable-parameter hashes are checked before and after each evaluation. RNG state is restored before training resumes. Each checkpoint has freshly computed DEV features/logits. Gradients are restricted to the predeclared TRAIN batches. Both checkpoints save LoRA/head hashes and verify the base state unchanged.

Required gates are unchanged: external macro F1 ≥ .75 and each recall ≥ .60; SHORTER/LONGER three-supported-class macro F1 ≥ .70; historical macro F1 ≥ .70 and each recall ≥ .60. Wrong predictions outside a challenge's supported classes count as errors. Aspirational metrics are reported separately. Only passing checkpoints are eligible, ordered by historical macro F1, external macro F1, minimum recall across both DEV sets, earlier step, then LoRA/head hashes. Incomplete training or either missing checkpoint is INDETERMINATE even if an available checkpoint passes.
