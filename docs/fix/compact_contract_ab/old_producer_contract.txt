## Output contract — return ONE JSON object (the canonical envelope), no markdown fences:
{"agent": "PROCESSOR", "doc_id": "<document id>", "items": [ ... ]}
`items` is ALWAYS a list. Each item is FLAT: one level, values are scalars or arrays of scalars only — NO nested objects and NO arrays of objects (express structure as MORE items, e.g. one item per finding/element/redaction).
Per item, supply the core fields: ref (the REF-*/segment id this item is about), kind, confidence (CONFIDENT|UNCERTAIN), verdict (only when you judge), ref_ids (flat array of all REF-* you cite; a search-discovered web reference is cited as a WEB-REF-* id, INFRA-042). Plus this agent's fields: {'section_id': 'string', 'draft_text': 'string', 'extraction_method': 'string', 'claims_referenced': 'array of claim_id strings', 'open_questions': 'array of strings', 'ref_ids': 'array of REF-* strings (optional)'}; required per item: ['section_id', 'draft_text', 'extraction_method']. (item_id, revision, ts are stamped by the runtime — you may omit them.)
Nothing to report -> {"agent": "PROCESSOR", "doc_id": "<id>", "items": []}
One item -> {"agent": "PROCESSOR", "doc_id": "<id>", "items": [{"ref": "REF-0001", "kind": "finding", "confidence": "CONFIDENT", "ref_ids": ["REF-0001"]}]}
