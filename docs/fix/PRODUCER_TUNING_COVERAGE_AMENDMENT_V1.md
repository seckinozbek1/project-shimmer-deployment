Historical aggregate limitations were already in the conversation; no packet-specific V2 comparison or authored target was consulted to design it. Seventeen generic tests and eight neutralise ? fail ? restore ? pass proofs passed before `POLICY_FREEZE.json`. That timestamp precedes source-only selection and the three fresh review sessions.

Every explicit claim remains a claim, including conflicting assertions. Contradiction alone does not create epistemic uncertainty. Uncertainty requires explicit unknown/unclear/uncertain/unresolved source semantics. A source can be uncertain while the annotation is unambiguous.

Gap atoms distinguish missing information from explicit answered questions. Attributes include date kinds, recorder, interpretation, status/state, quantity/identity and entry content/order. Atoms preserve subject/ordinal referent, attribute, relation, scope, unit, owned alias, exact refs and source-explicit origin. Source support is a literal owned substring. Material comparison excludes support/rationale wording. Finite alias normalization uses no fuzzy matching or embeddings.

The deterministic renderer emits only existing compact fields: span, claims, questions, uncertainty, status, refs. It sorts semantic arrays and renders typed gaps/uncertainty into stable canonical strings. Refusal retains the existing refusal envelope; examined-empty is distinct. Python still owns source, offsets, identities, order and reconstruction. No production schema or validator changed.
