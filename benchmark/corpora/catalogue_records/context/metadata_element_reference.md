# Metadata Element Reference, Cataloguing Handbook

Reference vocabulary used when reviewing returned catalogue records. Source: the Dublin Core
Metadata Element Set, published at https://www.dublincore.org/specifications/dublin-core/dces/
and reproduced here as the reviewing corpus.

This corpus contains no quantities of any kind. Every element is a named field with a prose
definition, and every rule that rests on it is a rule about presence, vocabulary or agreement
between fields rather than about magnitude.

---

## Section One , Element definitions

| Element | Definition |
|---|---|
| Contributor | An entity responsible for making contributions to the resource |
| Coverage | The spatial or temporal topic of the resource, the spatial applicability of the resource, or the jurisdiction under which the resource is relevant |
| Creator | An entity primarily responsible for making the resource |
| Description | An account of the resource |
| Format | The file format, physical medium, or dimensions of the resource |
| Identifier | An unambiguous reference to the resource within a given context |
| Language | A language of the resource |
| Publisher | An entity responsible for making the resource available |
| Relation | A related resource |
| Rights | Information about rights held in and over the resource |
| Source | A related resource from which the described resource is derived |
| Subject | The topic of the resource |
| Title | A name given to the resource |
| Type | The nature or genre of the resource |

## Section Two , Permitted resource types

| Type term | Applies to | Handling |
|---|---|---|
| Text | Written works, whether printed or manuscript | Standard reading room access |
| Image | Still visual representations | Surrogate supplied on request |
| Sound | Audio recordings of any carrier | Listening copy required before access |
| Dataset | Structured records intended for machine reading | Supplied under a data agreement |
| Collection | An aggregation described as a single unit | Item-level request required |

A resource type outside this vocabulary cannot be routed to a handling rule, so the record
cannot be actioned.

## Section Three , Rights statements

| Rights term | Meaning | Requires |
|---|---|---|
| Open | No restriction on consultation or copying | Nothing further |
| Attribution | Consultation open, reuse requires credit | A named creator |
| Restricted | Consultation by permission of the depositor | A stated source |
| Closed | No consultation during the stated embargo | A stated source and a named publisher |

## Section Four , Consistency requirements

A catalogue record is internally consistent when all of the following hold:

1. It states a title, a creator, a subject, a type and a rights term.
2. Its type is drawn from the permitted resource types in Section Two.
3. Its rights term is drawn from Section Three, and whatever that term requires is present.
4. A record whose rights term is restricted or closed states a source.

An inconsistency is a defect in the record rather than in the resource it describes. Cataloguer
error and genuine ambiguity in the material produce the same signature, so the assessment
records what is missing or inconsistent and leaves the resolution to the cataloguer.
