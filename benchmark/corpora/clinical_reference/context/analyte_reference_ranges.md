# Analyte Reference Ranges, Laboratory Handbook

Reference intervals used when reviewing returned result sheets. Source: the published
reference ranges for blood tests compiled at
https://en.wikipedia.org/wiki/Reference_ranges_for_blood_tests (public reference data,
reproduced here as the reviewing corpus).

A reference interval is the range within which the central 95 percent of a healthy reference
population falls. It is a review aid, not a diagnosis: a value outside the interval is a
result to look at, not in itself a finding about a person.

---

## Section One , Reference intervals by test

Note that the interval and its unit are recorded in separate columns, which is how the
published source presents them.

| Test | Reference range | Unit |
|---|---|---|
| Sodium | 135–145 | mmol/L |
| Potassium | 3.5–5.0 | mmol/L |
| Chloride | 95–105 | mmol/L |
| Total calcium | 2.1–2.5 | mmol/L |
| Albumin | 35–55 | g/L |
| Total bilirubin | 1.7–17 | umol/L |

## Section Two , Panel completeness

A returned result sheet states, for every result: the sample identifier, the test, the
measured value and the analysing laboratory. A result missing any of these cannot be
reconciled against the sheet it belongs to.

## Section Three , Sheet arithmetic

Where a sheet declares a batch, the sum of the declared result counts for each laboratory
equals the declared total result count for the sheet. A total that does not follow from its
parts cannot be relied on for either figure.

## Section Four , Consistency requirements

A result sheet is internally consistent when all of the following hold:

1. Every measured value falls inside the reference range recorded for its test in Section One.
2. Every result states its sample identifier, its test, its measured value and its
   analysing laboratory.
3. The declared result counts sum to the declared total result count.

A value outside its reference interval is recorded with the figure and the interval it falls
outside. The assessment records what is inconsistent and leaves interpretation to the
reporting clinician.
