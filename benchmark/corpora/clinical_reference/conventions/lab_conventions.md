# Review conventions: returned laboratory result sheets

Operator-authored rules for reviewing result sheets returned for batch review. Each finding
must cite the convention it rests on and at least one reference into the context corpus.

The reviewer is a quality function. The review produces observations. None are self-executing
and none are clinical judgements: interpretation belongs to the reporting clinician.

---

## CONV-L01 , conv-value-in-range [required]

The measured value stated for a result must fall inside the reference range recorded for its
test in Section One of the reference corpus. A measured value above the upper bound or below
the lower bound of that reference range is an irregularity. State the measured value, its
unit, and the bound it falls outside.

## CONV-L02 , conv-result-completeness [required]

Every result must state its sample identifier, its test, its measured value and its analysing
laboratory. A missing field is an irregularity. State which field is absent from which result.

## CONV-L03 , conv-count-arithmetic [required]

The declared result counts for each laboratory must sum to the declared total result count for
the sheet. Where the stated total does not follow from the declared counts, record the
discrepancy and state all the figures.

## CONV-L04 , conv-grounding [required]

Every finding must cite one convention and at least one reference into the context corpus. A
finding that identifies an irregularity must state the specific figures that conflict, the
result or sheet they belong to, and the reference range or rule they conflict with. Vague
findings such as "the values appear unusual" are not acceptable.

## CONV-L05 , conv-no-diagnosis [required]

Findings record what is inconsistent with the reference data, never what it means for a
patient. Do not write that a result indicates a condition, a severity or a prognosis. A value
outside a reference interval is a result to look at, and distinguishing a real abnormality
from a sampling or transcription error is the reporting clinician's task, not the reviewer's.
