# Device Class Reference

Reference material used when reviewing fleet monitoring log entries. Describes the standard
tolerance band and calibration requirement for each device class, independent of any single
quarter's log.

---

## Section One, standard tolerance bands

Class-A sensor: standard tolerance band 20 to 60 units. Requires a calibration authority
signature on every logged entry.

Class-B sensor: standard tolerance band 20 to 60 units. Self-calibrating; carries no
signature field.

Class-C sensor: standard tolerance band 70 to 110 units. Self-calibrating; carries no
signature field.

A locally adjusted range stated in a specific quarter's log entry overrides the standard band
for that quarter only, for the devices the adjustment names.

---

## Section Two, calibration authority

A calibration authority signature is complete only when the signing individual's role is
stated as holding a current calibration certificate for the device's class. A signature from
an engineering, operations, or supervisory role that does not state a current certificate is
recorded but not calibration-complete, and the device's most recent complete calibration
remains whatever entry last carried a qualifying signature.
