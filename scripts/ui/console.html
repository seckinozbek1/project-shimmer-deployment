Submit a run

A non-sensitive run (unchecked, the default) sends document text to cloud providers (Claude, GPT) and waives redaction for this run. A sensitive run (checked) keeps redaction on, but today it refuses to start (exit code 6) because the full LAW-IV masking layer ships inactive until the operator activates it; this checkbox does not activate it, it only declares intent.

The log column is the run's complete merged stdout/stderr, relative to the server's output root (SHIMMER_OUTPUT_DIR, default output/runs/); open it on the machine running the server, there is no download route for it.

Status vocabulary: completed is success. blocked, stopped_model_approval, stopped_redaction_gate and refused_sensitivity_layer_inactive are governance outcomes, not errors, the pipeline refused or paused on purpose. Note: exit code 5 (blocked) is also used for a draft-mode generation failure; check the log tail to tell which one happened. snapshot_conflict, operator_abort, interrupted (server restarted mid-run) and failed (including a run timeout) round out the vocabulary.
