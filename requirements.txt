# Project Shimmer: external Python dependencies (py -3.12)

# Model provider SDKs (REQUIRED). agent_wrapper.call_claude / call_gpt and the
#   model gate (model_registry.list_available_models) import these directly. Without
#   them every claude_api / openai_api agent degrades to "cannot verify / no key" and
#   generation returns no text. They are not transitive deps of anything else here, so
#   they MUST be listed explicitly or a fresh .venv cannot reach the API.

# transformers backs the local Qwen redactor (agent_wrapper.call_qwen / _load_qwen

#   but a directly-imported package belongs here explicitly so the redactor never depends
#   on a transitive chain.

# Input-format support (shared text_extract family: .pdf/.docx/.html/.htm/

#   degrades to a clear warning + skip rather than a crash.
# PDF parsing (corpus intake, document dating, embedding store)

# Multilingual support (INFRA-028): per-document language detection drives
#   per-language embedding-model selection, and direction-aware .docx output.

# Local pre-quantised model loading (agent_wrapper._load_qwen / call_qwen). The local

#   installed fails at import time, not gracefully. REQUIRED for --backend-profile
#   local and for the intake wizard's Sensitive mode redactor path; not needed for a
#   cloud-only run. Depends on torch, which is pinned above.
